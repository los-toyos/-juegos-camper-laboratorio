Camper Los Toyos · laboratorio táctil

🎮 Juegos para iPhone

He quitado los enlaces externos que daban problemas. Estos juegos están alojados ahora dentro de nuestro propio GitHub Pages y he seleccionado únicamente versiones con control táctil explícito.

Cómo probar: entra en un juego y usa directamente los controles que indico debajo. Todos incluyen un botón flotante ‹ Juegos Camper para volver a esta pantalla.
🏎️

Pixel Racer

Táctil ✓

Carreras verticales estilo pixel-art con tráfico, puntuación y dificultad progresiva.

Control: toca la mitad izquierda o derecha de la pantalla para girar. Toca para empezar/reiniciar. Jugar
👾

Arcade Fever

Botones táctiles ✓

Arcade de acción con controles móviles añadidos por el juego y botón de disparo independiente.

Control: cruceta táctil en pantalla + botón de disparo. Jugar
🌈

Spectrum Runner

1 toque ✓

Runner neón de reacción rápida, diseñado para jugar con un único gesto.

Control: toca la pantalla para saltar. Jugar
💚

Pulse Beat

Táctil ✓

Juego de ritmo/reacción con estética neón. El propio lienzo responde a pulsaciones.

Control: toca directamente los objetivos que aparecen en la pantalla. Jugar
🕹️

Arcade Classic

Botones táctiles ✓

Arcade clásico con interfaz retro y controles móviles visibles.

Control: cruceta táctil + botón de acción/disparo. Jugar
🐍

Snake Mobile

D-pad ✓

Versión orientada a móvil con gráficos incrustados y botones direccionales en pantalla.

Control: botones ▲ ▼ ◀ ▶ visibles en el propio juego. Jugar
