# Mi Jardín Inteligente

PWA móvil para gestionar plantas y cuidados.

## v0.1
- Biblioteca personal de plantas.
- Fichas con foto, zona, ubicación, exposición y sustrato.
- Riego dinámico según temperatura y lluvia usando Open-Meteo.
- Abono, poda y trasplante.
- Calendario mensual de tareas.
- Historial básico de cuidados.
- Exportación ICS compatible con Google Calendar.
- Datos guardados localmente en el dispositivo.

## Próximas fases
- Diagnóstico de plantas mediante IA a partir de fotografías.
- Sincronización OAuth con Google Calendar.
- Notificaciones.
- Persistencia opcional en nube.
